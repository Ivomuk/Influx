Real-Time Eligibility API
Lender API call  ──▶  Feature Store  ──▶  Decision Engine  ──▶  Response

File				Layer				What it does
dim3_feature_store.txt		Dimension 3 — data serving	Hot/warm/cold in-memory store. Hot path refreshed every 15 min. Warm path updated per lender 								event. Cold path refreshed by daily batch.
dim3_eligibility_api.txt	Dimension 3 — API		check_eligibility() and check_eligibility_batch(). Reads from feature store, runs decision engine, 							returns external-safe EligibilityResponse within 200ms p99.

Lender Feedback Loop

Lender submits report  ──▶  Validate  ──▶  Ingest  ──▶  Reconcile / Update / Compliance check


File				Layer			What it does
dim6_config.txt			Dimension 6 — config	All thresholds for feedback validation, outcome tracking, fairness monitoring, and explainability
dim6_lender_feedback_api.txt	Dimension 6 — feedback	validate_lender_report → ingest_lender_report → reconcile_lender_vs_observed → 										compute_near_realtime_exposure_update → detect_lender_noncompliance
dim6_outcome_tracking.txt	Dimension 6 — outcomes	store_decision_snapshot → compute_realised_outcomes → compute_calibration_metrics → 									compute_dsi_accuracy → compute_fairness_metrics → generate_all_explanations
